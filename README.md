# LocalFileTools
## Download for Windows

**[Download LocalFileTools installer](https://github.com/TejasKoravanavar/LocalFileTools/releases/latest/download/LocalFileTools-Setup.exe)**

Run `LocalFileTools-Setup.exe` on Windows 10/11. Internet may be needed during the first installation. The “Source code” downloads are for developers.

LocalFileTools is a Windows desktop app for local PDF and image workflows. Processing happens on the computer. It includes PDF merge, split, organize, conversion, OCR, compression, page editing, security, comparison, and image conversion and editing tools.

## Install

Download `LocalFileTools-Setup.exe` from the GitHub Release. Run it on a compatible Windows 10 or 11 laptop. Setup chooses the x86 or x64 app and downloads Microsoft .NET 10 Desktop Runtime into the app folder only when it is missing. The first installation may require internet access. See `INSTALL.md` for details.

## Build from source

See `BUILD.md`. The source uses .NET 10, WPF, PDFsharp, Docnet/PDFium, Magick.NET, and Tesseract. The supplied logo is embedded in the app and installer.

The installer is unsigned. Windows may show a SmartScreen warning on a newly downloaded copy.
